# Lab 03 - Currency Exchange Cron

## Project structure

- `app/` - contains application files.
- `data/` - stores exchange-rate JSON files.
- `.env` - stores environment variables.
- `cronjob` - defines daily and weekly cron schedules.
- `currency_exchange_rate.py` - requests exchange rates and saves JSON in `data/`.
- `docker-compose.yml` - builds and runs the container with cron.
- `Dockerfile` - installs Python dependencies and cron.
- `entrypoint.sh` - initializes logs, exports environment variables and starts cron.
- `error.log` - stores errors generated by the Python script.
- `sample.env` - provides an example of environment variables.
- `readme.md` - contains project documentation and usage instructions.

## Build and start

Place `currency_exchange_rate.py` in this directory. Start the API service that the script calls before running the scheduled tasks. The script's default `http://localhost:8080/` points to the cron container itself; configure its API URL to a reachable service address (for example, `http://host.docker.internal:8080/` when the API runs on the host). Set `API_KEY` if needed.

```bash
docker compose up -d --build
docker compose ps
```

## Schedule

- Every day at 06:00: MDL to EUR, previous calendar day.
- Every Friday at 17:00: MDL to USD, seven days earlier (previous Friday). This is a single date, not a whole-week series.

The schedule uses the container's local timezone. The image includes `tzdata`, and Compose sets `TZ=Europe/Chisinau`.

## Verify cron and output

```bash
docker compose exec currency-cron cat /etc/cron.d/currency-cron
docker compose exec currency-cron ps -ef
docker compose exec currency-cron tail -f /var/log/cron.log
docker compose logs -f currency-cron
```

### Testing Cron Execution

To verify that cron executes scheduled tasks, temporarily add the following line to the `cronjob` file:

```cron
* * * * * root echo CRON_EXECUTED >> /var/log/cron.log 2>&1
```

This task writes `CRON_EXECUTED` to `/var/log/cron.log` every minute.

**Note:** The `cronjob` file must use Unix-style line endings (LF) and end with a newline character (`\n`). Otherwise, cron may fail to execute the last task.

Rebuild and restart the container to apply the changes:

```bash
docker compose up -d --build --force-recreate
```

Wait 1-2 minutes and check the cron log:

```bash
docker compose exec currency-cron cat /var/log/cron.log
```

Expected output:

```text
CRON_EXECUTED
CRON_EXECUTED
```

The repeated messages confirm that cron executes scheduled tasks and writes their output to `/var/log/cron.log`.

After verification, remove the temporary task from `cronjob` and rebuild the container to restore the original schedule.

## Stop

```bash
docker compose down
```
